# CRM Sales Pipeline Analysis

## Project Overview

This project analyzes CRM sales pipeline data to understand sales performance, product performance, and sales agent performance.

The analysis was completed using Google Sheets, Pivot Tables, and data visualization.

## Business Questions

- How many opportunities are in the sales pipeline?
- What is the overall win rate?
- Which product generates the highest sales value?
- Which product has the highest win rate?
- Which product has the highest average deal value?
- Which sales agents generate the most sales?
- Which sales agent has the highest average deal value?

## Tools Used

- Google Sheets
- Pivot Tables
- Data Analysis
- Data Visualization

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Opportunities | 8,800 |
| Won Opportunities | 4,238 |
| Overall Win Rate | 48.15% |
| Total Sales Value | 10,005,534 |

## Key Findings

1. **GTXPro** generated the highest total sales value at **3,510,578**.
2. **GTX Plus Pro** had the highest product win rate at **49.48%**.
3. **GTK 500** had the highest average deal value at **26,707.47**, despite having only 15 won deals.
4. **Darcel Schlecht** had the highest number of won deals with **349**.
5. **Darcel Schlecht** also generated the highest total sales value among sales agents at **1,153,214**.
6. **Elease Gluck** had the highest average deal value per won deal at approximately **3,614.94**.
